# The Problem

### Current Teacher Workflow

```text
Create Lesson
      ↓
Open Claude
      ↓
Generate Content
      ↓
Copy to Word
      ↓
Format Template
      ↓
Create Worksheet
      ↓
Create Assessment
      ↓
Submit to Principal
```

### Pain Points

🔴 Multiple AI prompts

🔴 Repetitive formatting

🔴 Manual documentation

🔴 No lesson repository

🔴 No review workflow

# User Research

### Survey Conducted

👩‍🏫 Teachers Interviewed

4 Initial Responses

---

## Key Findings

| Insight            | Observation             |
| ------------------ | ----------------------- |
| AI Adoption        | 100% use ChatGPT/Gemini |
| Planning Time      | 30–120 mins             |
| Assessment Time    | 1–5 hrs/week            |
| Main Need          | Faster documentation    |
| Willingness to Try | 75% Yes                 |

---

# Root Cause Analysis

Teachers do NOT have a content problem.

Teachers have a workflow problem.

### Existing Situation

```text
AI Generates Content
           ❌
AI Does Not Manage Workflow
```
